# Strategy Data Dictionary v1

Короткий словарь полей для стратегии и индикаторов.
Цель: простое чтение, единые имена, удобное редактирование.

## Свечные данные: d

Формат текущей свечи (без скобок):
- c.o, c.h, c.l, c.c, c.v, c.t

Формат с лагом (в скобках):
- c(0).o - текущая (эквивалент c.o)
- c(-1).h - предыдущая
- c(-10).l - 10 свечей назад

Расшифровка:
- c = candle
- o = open
- h = high
- l = low
- c = close
- v = volume
- t = unix time (seconds)
- lag опционален (по умолчанию 0)



## Индикаторы: i

Все индикаторы — функции с опциональным lag (по умолчанию 0).

### BB — Bollinger Bands

```js
i.bb(lag) -> { u, m, l } | null
```
- u = upper band
- m = middle band (SMA)
- l = lower band

Примеры:
- i.bb(0).u      -> верхняя граница BB на текущей свече
- i.bb(-1).m     -> средняя BB на предыдущей свече
- i.bb(-5).l     -> нижняя граница BB 5 свечей назад

Ширина полосы (bwNorm):
- `(bb.u - bb.l) / bb.m` — нормализованная ширина (без единиц)

### ST — Stochastic

```js
i.st(lag) -> { k, d } | null
```
- k = %K (быстрая линия, 0..100)
- d = %D (сигнальная линия, SMA от %K)

Примеры:
- i.st(0).k      -> текущий %K
- i.st(-1).d     -> предыдущий %D
- i.st(0).k > 80 -> перекупленность

### SMA — Simple Moving Average

```js
i.sma(lag) -> number | null
```
Возвращает одно число.

Примеры:
- i.sma(0)       -> текущее SMA
- i.sma(-1)      -> предыдущее SMA

### MACD

```js
i.macd(lag) -> { macd, signal, histogram, histogramColor } | null
```
- macd = MACD-линия (быстрая EMA − медленная EMA)
- signal = сигнальная линия (EMA от MACD)
- histogram = macd − signal
- histogramColor = '#26a69a' (положительный) / '#ef5350' (отрицательный)

Примеры:
- i.macd(0).histogram         -> текущая гистограмма
- i.macd(-1).histogram        -> предыдущая гистограмма
- i.macd(0).macd > i.macd(0).signal  -> macd выше сигнала

Кроссовер гистограммы через 0:
```js
const h0 = i.macd(0).histogram;
const h1 = i.macd(-1).histogram;
if (h1 <= 0 && h0 > 0) buy  = 1;  // пересечение вверх
if (h1 >= 0 && h0 < 0) sell = 1;  // пересечение вниз
```

### ATR — Average True Range

```js
i.atr(lag) -> number | null
```
Возвращает одно число (значение ATR).

Примеры:
- i.atr(0)       -> текущий ATR
- i.atr(-1)      -> предыдущий ATR

Важно:
- Все индикаторы возвращают null если данных недостаточно (начало истории)
- Всегда проверяй на null перед использованием: `if (bb0 && bb0.m > 0)`



## Сделки: t

Формат последней сделки (без скобок):
- t.t, t.dir, t.start, t.end, t.win

Формат с лагом (в скобках):
- t(0).t - последняя (эквивалент t.t)
- t(-1).dir - предпредыдущая
- t(-2).win - ещё давнее

Расшифровка:
- t = trade
- t = take (размер позиции)
- dir = direction: "buy"/"sell"
- start = unix time открытия
- end = unix time закрытия
- win = result: "win"/"loss"
- lag опционален (по умолчанию 0, отсчёт от конца истории)

Вспомогательные методы:
- t.openCandle()   -> возвращает c (свеча входа)
- t.closeCandle()  -> возвращает c (свеча выхода)

Примеры:
- t.t             -> размер позиции последней сделки
- t.dir           -> "buy" или "sell"
- t.start         -> время открытия последней сделки
- t(-1).win       -> результат предпредыдущей сделки
- t.openCandle().o -> цена открытия свечи входа последней сделки



## Сигналы: signalsSource

`signalsSource` — скрипт, который считается на каждой свече и записывает значения в 3 выходных переменных.  
Отображается в отдельной панели под основным графиком.

### Выходные переменные

| Переменная | Линия    | Диапазон   | По умолчанию |
|------------|----------|------------|--------------|
| `signal`   | teal пунктир (верхняя) | −1..+1 | 0 |
| `signal2`  | teal пунктир (нижняя)  | −1..+1 | 0 |
| `signal3`  | оранжевая (composite)  | −1..+1 | 0 |

Шкала панели фиксирована: −1 до +1.  
Ось 0 по центру.

### Контекст выполнения

Те же переменные, что и в `logicSource`:
- `c(lag)` — свечи
- `i.*` — индикаторы
- `t(lag)` — сделки

### Текущая логика (autorun)

```
signal  = +0.5 если флет, иначе 0    — верхняя граница зоны флета
signal2 = −0.5 если флет, иначе 0    — нижняя граница зоны флета
signal3 = позиция цены в BB [−0.5..+0.5], только в зоне флета
```

**Определение флета** (относительная ширина BB):

```js
const bwNorm = (bb0.u - bb0.l) / bb0.m;       // нормированная ширина
const maxBw = max(bwNorm за последние 200 свечей);
const relBw = bwNorm / maxBw;
isFlat = relBw > 0.05 && relBw <= 0.5;         // не шум и не тренд
```

**signal3 — позиция цены внутри BB:**

```js
const pos = (close − bb.m) / ((bb.u − bb.l) / 2);  // −1..+1
signal3 = pos * 0.5;                                  // → −0.5..+0.5
```
- +0.5 = цена у верхней полосы → сигнал на продажу
- −0.5 = цена у нижней полосы → сигнал на покупку
- 0    = цена у средней линии

### Пример: флет + MACD кроссовер

```js
signal  = isFlat ?  0.5 : 0;
signal2 = isFlat ? -0.5 : 0;
if (isFlat) {
    const h0 = i.macd(0).histogram;
    const h1 = i.macd(-1).histogram;
    if (h1 <= 0 && h0 > 0) signal3 =  0.5;   // buy signal
    if (h1 >= 0 && h0 < 0) signal3 = -0.5;   // sell signal
}
```
